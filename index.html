Como o Robô Funciona?
1. Roleta Viciada: O algoritmo sorteia 50 números, mas dá mais chances para dezenas quentes e dezenas que faltam para fechar o ciclo.
2. Validador: O robô rejeita jogos com desequilíbrio (ex: aceita apenas entre 22 e 28 pares) e evita colunas inteiras marcadas.
3. Aposta-Espelho: O sistema sempre gera um bilhete secundário com as 50 dezenas que ficaram de fora, garantindo proteção total caso o bilhete principal faça 0 acertos.
